# Legionshield

Escudo de Mestre Agnóstico para RPG.

Um assistente e organizador para mestres de RPG de mesa, projetado para ser agnóstico em relação a sistemas, permitindo gerenciamento de campanhas, jogadores, sessões e recursos como dados 3D, notas e mapas (canvas).

## Funcionalidades Principais

- **Gerenciamento de Campanhas e Jogadores**: Estrutura em pastas organizadas, suportando múltiplos perfis.
- **Editor Rico e Multi-Abas**: Edição de notas em formato rico com navegação por abas.
- **Rolador de Dados 3D**: Interface integrada de rolagem com simulação física 3D local.
- **Sessões e Canvas**: Visualização e manipulação interativa com suporte a nós de imagens e integração de elementos gráficos via React Flow.
- **Persistência de Dados**: Salvamento automático do estado das sessões, personagens e anotações localmente através de SQLite.

## Tecnologias

- **Frontend**: React, React Flow, Zustand, Tiptap, TailwindCSS.
- **Desktop**: Electron, Vite.
